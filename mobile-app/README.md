# Code Mentor Mobile (UI Only)

Flutter UI-only app scaffold for the mobile experience.

## Structure
- lib/main.dart: App entry
- lib/app.dart: App shell and bottom navigation
- lib/theme/app_theme.dart: Material 3 theme
- lib/screens/: Main UI screens
- lib/widgets/: Reusable widgets

## Run
1. Install Flutter SDK
2. Run `flutter pub get`
3. Run `flutter run`

No backend/API calls are included in this version.
